# Einführung in die chinesische Zeichenlehre

Eine Vortragspräsentation von **Mandarin Maverick – Fast Track Chinese**
über die Entstehung der Schrift und die Bildung der chinesischen
Schriftzeichen. 73 Folien, dazu drei Übungsquizze.

## Aufrufen

Die Präsentation läuft im Browser, ohne Installation und ohne Server:
`index.html` öffnen. Über GitHub Pages ist sie unter der Adresse des
Repositorys erreichbar.

## Bedienung

| Taste | Wirkung |
|---|---|
| `→` `←` `Leertaste` | blättern |
| `Pos1` `Ende` | erste bzw. letzte Folie |
| `I` | zum Inhaltsverzeichnis |
| `Esc` | Lesekasten schließen |
| `L` | roten Cursorpunkt aus- und einschalten |

Unten am Bildrand liegen zwei Zeilen: die Steuerleiste mit
„☰ Inhaltsverzeichnis" und den Pfeilen, darunter ein Punkt je Folie. Beim
Überfahren eines Punktes erscheint der Folientitel.

**Lesekästen.** Wo eine Folie oben rechts „zusätzliche Info" trägt, öffnet
ein Klick den Kasten und ein zweiter schließt ihn wieder; dasselbe gilt für
die Vertiefung darin.

**Abbildungen.** In Bildreihen zeigt der Cursor über einem Bild dieselbe
Abbildung groß in der Folienmitte.

## Aufbau

| Datei | Inhalt |
|---|---|
| `index.html` | die Präsentation, 73 Folien |
| `theme.css` | das Gestaltungssystem nach MM-Designhandbuch v1.4 |
| `deck.js` | Steuerung: Blättern, Lesekästen, Zeitleiste, Lupe |
| `quiz-1/2/3.html` | drei Quizze nach Schwierigkeitsgrad |
| `quiz.css`, `quiz.js` | Gestaltung und Auswertung der Quizze |
| `bilder/`, `assets/` | Abbildungen, Filme, Bildmarke |
| `Reader-Die-chinesischen-Schriftzeichen.pdf` | Begleittext zum Nachlesen |

Die drei Quizze fragen gestuft ab: Stufe 1 den Folieninhalt, Stufe 2
zusätzlich die Kurztexte der Lesekästen, Stufe 3 auch deren Vertiefungen.

## Hinweise

Die chinesische Bildschirmschrift wird von Google Fonts nachgeladen. Ohne
Internetverbindung greift die Schrift des Betriebssystems — auf macOS und
Windows ist eine geeignete vorhanden.

Alle Datei- und Ordnernamen sind bewusst frei von Umlauten und
Leerzeichen: Der Webserver unterscheidet Bytefolgen, die macOS still
ausgleicht.

Zum Ausdrucken gibt der Druckdialog jede Folie als eigene Querformatseite
aus. Die interaktiven Teile — Zeitleiste, Lupe, Kategorienweg und die
Quizze — sind dabei naturgemäß nicht enthalten.
